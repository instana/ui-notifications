# Build 288

Build 288 is released on 13 January 2025.

## Features

### Monitoring large language models with vLLM (public preview)

Instana now supports monitoring large language models with vLLM. You can export traces from you vLLM application to Instana and monitor it with ease. For more information, see [Monitoring large language models (LLMs) with vLLM](https://www.ibm.com/docs/en/instana-observability/current?topic=cmst-monitoring-large-language-models-llms-vllm-public-preview
).

### Nutanix sensor

Instana now supports monitoring the Nutanix datacenters. For more information, see [Monitoring Nutanix](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-nutanix).

### Synthetic monitoring

- Synthetic monitoring PoP can be installed in an air-gapped environment. For more information, see [Deploying self-hosted Synthetic PoP with `popctl`](https://www.ibm.com/docs/en/instana-observability/current?topic=pop-using-popctl-commands#deploying-self-hosted-synthetic-pop-with-popctl
).

### Support for etcd 3.5

- The etcd sensor now supports monitoring etcd v3.5. For more information, see [Monitoring etcd](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-etcd).

### Support for Apache Kafka 3.9

The Kafka sensor supports Apache Kafka 3.9. For more information, see [Monitoring Kafka](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-kafka).

## Improvements

### Cassandra 4.x

Cassandra calls can now be linked to Cassandra 4.x cluster infrastructure entities.

### RBAC application access scope to access application APIs
To use an API token for accessing application APIs, now you need RBAC access scope of applications.

### Showing previously invisible entity types

On the Analyze Infrastructure page, Instana now shows entity types that were previously not visible:
- Component Metrics Entity
- EC2 Tags Collector
- Entity Statistics
- Kubernetes Endpoint
- Processing Statistics
- Region Entity
- Tenant Unit Entity

### Synthetic monitoring

- A new column **IP Address** is added in the **Locations** page. It displays external IP addresses of managed locations. 
- A new filter **Error message** is added in the **Synthetic Smart Alert** Scope section.

## Fixes

### Custom service mapping

Previously, the `instana.service.name`, `jvm.args`, `oracledb.sid`, and `service.default_name` tags were unavailable for custom service mapping. This issue is now resolved.

### Synthetic monitoring
The following security vulnerabilities are fixed in Synthetic PoP:
- CVE-2024-21538
- CVE-2024-52798
