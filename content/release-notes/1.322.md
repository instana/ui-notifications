## Improvements

The following improvements are provided in release 1.0.322:

### Outbound and internal call rates in service and endpoint dashboards

Dashboards for services and endpoints now display the rate of outbound calls (calls to downstream services) and internal calls
(calls within the service implementation that use explicit monitoring instrumentation).

### Batch pause and resume for Synthetic tests

You can now pause or resume multiple synthetic tests simultaneously from the Synthetic Monitoring tests page.
For more information, see [The Synthetic tests tab](https://www.ibm.com/docs/en/instana-observability?topic=monitoring-synthetic-tests).
