## Features

The following features are added in release 1.0.309:

### AWS metric streams (public preview)

Instana now supports Amazon CloudWatch Metric Streams that streams AWS metrics directly to Instana in real time. It replaces the traditional polling-based mechanism. AWS CloudWatch streams data through Amazon Data Firehose to an HTTP endpoint in the Instana backend.

This capability is introduced as a public preview to enhance monitoring of AWS services within Instana by providing the following benefits:

- Reduced latency from approximately 10 minutes to 2–3 minutes
- Reduced ingestion costs per metric
- Simplified setup and configuration
- Agentless architecture
- Faster onboarding of new AWS services

For more information, see [AWS metrics streams](../../ecosystem/aws-metricstreams/index.md).

### Smart Alerts hub

Instana now includes the **Smart Alerts** tab in the **Events** page to access and manage all Smart Alerts. The **Smart Alerts** tab provides the following features:

- **Filter** panel to refine and view specific Smart Alerts based on selected criteria.
- **Configure columns** option to customize the Smart Alerts table by selecting the columns to display.

These features help you focus on relevant alerts and streamline event monitoring. For more information, see [Smart Alert Hub](../../events/alert_hub.md).


## Improvements

The following improvements are provided in release 1.0.309:

### Application Smart Alerts

Instana now supports the use of custom call metrics as filters in Application Smart Alerts. For more information, see [Custom call metrics](../../application_monitoring/custom_call_metrics.md).

### Configuring K8sensor polling interval

You can now configure the K8sensor polling rate by using the **`k8s_sensor.pollrate`** parameter in Helm charts or `InstanaAgent` custom resources. For more information, see [Configuring polling interval](../../ecosystem/kubernetes/index.md#configuring-polling-interval).

## Fixes

The following issues are fixed in release 1.0.309:

### Added active instances count metric for Oracle RAC

The active instances count is now added as a metric in Oracle RAC. Previously, the built-in event that used the inactive instances count was inaccurate and inconsistent. With this fix, custom events can now be created by using the active instances metric for more reliable monitoring.
