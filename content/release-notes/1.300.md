Release 1.0.300 is released on 14 July 2025.

Note:
For the latest agent, tracer, and sensor updates, see the following release notes:

- [Agent releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-agent)
- [Sensor releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-sensor)
- [Tracer releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-tracer)

## Features

The following features are added in release 1.0.300:

### Infrastructure smart alert incidents

You can now configure infrastructure smart alerts to automatically trigger incidents. This feature enables event correlation and recommended actions for each incident that is generated by the smart alert.

## Improvements

The following improvements are provided in release 1.0.300:

### OpenTelemetry

The OpenTelemetry calls are now improved to more accurately link to related infrastructure.

## Fixes

The following issues are fixed in release 1.0.300:

### Infra Linking
Previously, calls created from the vertx.client span were not linked to a Kubernetes service. This issue is now fixed.
