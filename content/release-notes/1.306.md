## Features

The following features are added in release 1.0.306:

### AI gateway (public preview)

Now you can connect watsonx or other external Large Language Model (LLM) services with Instana. The AI gateway feature gives you greater control over the AI models driving your observability workflows—ensuring they align with your organization’s internal policies, performance benchmarks, and data governance standards.

For more information, see [AI gateway](https://www.ibm.com/docs/en/instana-observability/saas?topic=instana-ai-gateway-public-preview).


### Data granularity

A new capability is now introduced to help you better understand your data ingest usage.

You can now see the contributors to your total data ingest directly from the **Account & Billing** section under the **Usage** tab. This feature provides the following benefits:

- Breaks down usage by **Traces** and **Synthetics**.
- Gives you clearer visibility into what's driving your data consumption.

This feature makes it easier to monitor and manage your data ingest, so you can stay in control of your usage.


### GenAI observability

A new product area for viewing the GenAI application metrics and traces is now available in the Instana UI.

You can now view the following data on the GenAI observability dashboard in the Instana UI:

- LLM metrics with their cost, latency, and other performance details
- LLM traces, including their input prompts and output responses

This feature provides a wholistic view of GenAI observability. For more information, see [Monitoring LLMs](https://www.ibm.com/docs/en/instana-observability/saas?topic=llms-generative-ai-observability).


## Improvements

The following improvements are provided in release 1.0.306:

### Simple metric value in Smart Alert notifications

Simplified human readable metric field is added to all types of Smart Alerts except Synthetic and SLO, for all the Alert channels.
All the Alert channels now have checks to ensure that if metrics are empty, then they will not be included in the alert notification.

### Synthetic monitoring

The Synthetic PoP BrowserScript playback engine now uses Chromium 138.

## Fixes

The following issues are fixed in release 1.0.306:

### Application Perspectives

Fixed an issue where using the OpenTelemetry resource tag `otel_resource.service.name` in application perspective configuration caused failures when creating new or editing applications.

### Synthetic monitoring

The following security vulnerabilities are fixed in Synthetic PoP:
- CVE-2025-7783
- CVE-2025-55163
- CVE-2025-58057
