## Features

The following features are added in release 1.0.297:

### Synthetic monitoring

New Synthetic monitoring endpoints are available to support on-demand Synthetic test executions. For more information, see [OpenAPI](https://instana.github.io/openapi/#operation/createSyntheticTestCICD).

To obtain support for the new CI/CD execution capability, upgrade the Synthetic PoP to version 1.2.18.

## Improvements

The following improvements are provided in release 1.0.297:

### Custom call tags and metrics

Previously, if a call was created from two spans (exit and entry), custom call tags and metrics would be extracted only from one of the spans, with the entry span taking precedence. Now, custom call tags and metrics are extracted and merged from both spans, with values from the entry span taking precedence.

### Filtering calls by OpenTelemetry span attributes with array-type values

OpenTelemetry trace data can provide [span attributes](https://opentelemetry.io/docs/concepts/signals/traces/#attributes) with different types of values: string, Boolean, numeric, or arrays. These attributes can be viewed as part of call details, but only attributes of type "string" were parsed for filtering and grouping. Now, span attributes with array-type values, particularly the `http.request.header.<key>` attributes introduced in recent versions of the OpenTelemetry [semantic conventions](https://opentelemetry.io/docs/specs/semconv/registry/attributes/http/), can also be used for filtering and grouping calls.

### Synthetic monitoring

- You can now create an SSL certificate test, which uses self-signed certificates in the UI. For more information, see [No certificate error](https://www.ibm.com/docs/en/instana-observability/saas?topic=monitoring-deploying-self-hosted-pop#no-certificate-error).
- The Synthetic PoP now uses Chromium 127.
- Google Chrome no longer supports the Selenium IDE browser extension. Use the Selenium IDE Electron app as a replacement. For more information, see [How to record basic scripts](https://www.ibm.com/docs/en/instana-observability/saas?topic=scripts-selenium-ide#how-to-record-basic-scripts).
- The [synctl](https://github.com/instana/synthetic-synctl) tool is enhanced to support the new endpoints related to the on-demand Synthetic test execution type.
