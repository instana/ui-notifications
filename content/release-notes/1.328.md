## Features

The following features are added in release 1.0.328:

### Adaptability and seasonality parameters for adaptive threshold

Adaptive threshold now supports configuring **adaptability** and **seasonality** parameters directly in the Smart Alert settings. Adaptability controls how quickly the threshold model responds to changes in your metrics, while seasonality lets you specify or override the detected seasonal pattern (none, daily, or weekly). These settings were previously available only as a private preview and are now generally available. The default adaptability value is decreased from 1.0 to 0.3.

For more information, see [Adaptive threshold](../../adaptive_threshold/index.md).

## Improvements

The following improvements are provided in release 1.0.328:

### Power HMC temperature metrics in custom dashboards

Added support for monitoring inlet, CPU, and baseboard temperature metrics of Power HMC systems in custom dashboards. You can now select temperature metrics for individual sensors when you configure a dashboard widget. For more information, see [Managed system energy monitoring](../../ecosystem/pHMC/index.md#managed-system-energy-monitoring).
