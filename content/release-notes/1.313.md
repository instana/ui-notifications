## Features

The following features are added in release 1.0.313:

### Monitor CustomResourceDefinition and custom resource in Kubernetes clusters

The K8sensor now monitors CustomResourceDefinitions (CRDs) and their custom resources. It exposes them as infrastructure entities. For more information, see [Monitoring custom resources](https://www.ibm.com/docs/en/instana-observability/1.0.313?topic=instana-monitoring-kubernetes#monitoring-custom-resources__title__1).

### Support for monitoring Google ADK

Instana now supports monitoring of Google ADK. For more information, see [Monitoring Google ADK](https://www.ibm.com/docs/en/instana-observability/1.0.313?topic=frameworks-monitoring-google-adk).

## Improvements

The following improvements are provided in release 1.0.313:

### Unbounded analytics

This release improves the search performance for log messages filters in unbounded analytics.
