# Build 290

Build 290 is released on 10 February 2025.

## Features

Build 290 adds the following features:

### Business monitoring

Added a process ID column to differentiate between different processes with the same name.

### Multi-closing issues and incidents

The multi-close feature enables users to close multiple issues or incidents at once, helping to streamline workflows and reduce operational overhead. For more information, see [Multi-closing issues and incidents](https://www.ibm.com/docs/en/instana-observability/current?topic=alerts-multi-closing-issues-incidents).

### Retriggering open alerts after maintenance window expiry

Users can now configure their maintenance windows to trigger alerts for any events that were opened during an active maintenance window but are still unresolved after the window expires. For more information, see [Scheduling maintenance windows](https://www.ibm.com/docs/en/instana-observability/current?topic=alerts-scheduling-maintenance-windows#step-1-schedule-window).

### Support for CockroachDB 24.3.3

The Instana CockroachDB sensor now supports CockroachDB 24.3.3. For more information, see [Monitoring CockroachDB](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-cockroachdb).

### Support for MySQL 8.4 and 9.1

The Instana MySQL sensor now supports MySQL 8.4.x and 9.1.x. For more information, see [Monitoring MySQL](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-mysql).

### Support for HAProxy 3.1.3

The Instana HAProxy sensor now supports HAProxy 3.1.3. For more information, see [Monitoring HAProxy](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-haproxy).

### Support for TIBCO BW 6.11.0

The Instana TIBCO BW sensor now supports TIBCO BW 6.11.0. For more information, see [Monitoring TIBCO BW](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-tibco-bw).


## Improvements

Build 290 provides the following improvements:

### Synthetic monitoring

- Now you can download the test scripts that you uploaded for an API Script or a Browser Script test. The **Download .zip file** option is available when you create or edit the test in advanced mode.
- The **Download Recording** button in the test result details page is now replaced with the **View Recording** button.
- The [synctl](https://github.com/instana/synthetic-synctl) tool now supports the **Get Synthetic Metrics** API.


## Fixes

Build 290 fixes the following issues:


### Misleading items per page count

In some tables, the default value of items per page was misleading. In the **Applications** > **Error Messages** table, for example, items per page was set to 20 by default, but only 10 items were shown. This bug is now fixed.

### Synthetic monitoring

The following security vulnerabilities are fixed in Synthetic PoP:

- CVE-2023-5590
- CVE-2024-47535

### RBAC application access scope to include application APIs

Previously, personal API tokens ignored RBAC application access limits. Now, personal API tokens with limited application access can access only the listed applications.

### Kubernetes monitoring polling frequency

The polling frequency for Kubernetes monitoring is now automatically set by the agent operator to 10 seconds.
