## Features

The following features are added in release 1.0.310:

### Dependency view for websites and mobile applications

Instana provides a clear view of direct service dependencies for websites and mobile applications. The **Dependency** tab displays both graph and table views, showing the services each application calls with key metrics, such as call volume, error rate, and average latency. In addition, you can view the detected issues highlighted at the website or service level, including their severity.

For more information, see [Websites dependency](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-monitoring-websites#concept_2__title__1) and [Mobile app dependency](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-monitoring-mobile-applications#concept_1__title__1).

## Improvements

The following improvements are provided in release 1.0.310:

### Azure App Service agent installation

The Azure App Service agent installation now includes a script-based installation for automating deployments on Windows hosts.

### Helm and Linux s390 support for OTEL Collector installation

You can now install the OpenTelemetry Collector by using Helm or on the Linux s390 platform directly from the Instana UI. Previously, these installations required following external documentation. Now the Instana UI automatically displays the appropriate installation commands.
