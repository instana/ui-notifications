## Features

The following features are added in release 1.0.305:    

### Mobile app monitoring 

You can now view error messages and stacktraces generated for ANR beacons in the performance dashboard. For more information, see [collecting ANR details](https://www.ibm.com/docs/en/instana-observability/1.0.303?topic=instana-monitoring-mobile-applications).

### Synthetic monitoring

To streamline your synthetic monitoring experience, the following updates are now available on the Synthetic monitoring dashboard in the Instana UI:

- A contextual onboarding banner for synthetic monitoring is added on the Synthetic tests page. 
- The **Test execution** filter is now available on the following pages: **Synthetic tests**, **Summary**, and **Results**. The test execution types are also supported in [Synthetic Smart Alerts](https://www.ibm.com/docs/en/instana-observability/1.0.302?topic=monitoring-smart-alerts-synthetic) and [Synthetic Service Levels](https://www.ibm.com/docs/en/instana-observability/1.0.301?topic=instana-service-level-objectives-slos). 
- You can now create an on-demand test from the UI. For more information, see [On-demand synthetic tests](https://www.ibm.com/docs/en/instana-observability/1.0.303?topic=monitoring-synthetic-test-execution-types).

## Improvements

The following improvements are provided in release 1.0.305:

### Application perspectives

Added a safeguard that limits 50 application perspectives per call. This limitation applies separately to "source applications" and "destination applications". For more information, see [Limitations of application perspectives](https://www.ibm.com/docs/en/instana-observability/1.0.304?topic=applications-application-perspectives).

### Live tail of logs (public preview)

Instana UI is updated for easier log filtering. This enhancement includes improved search functionality and visual enhancements for a better user experience.

### Removed Customer Adoption page

The **Customer Adoption** page is removed intentionally to simplify the user experience.

## Fixes

The following issues are fixed in release 1.0.35:

### ELK integration

Fixed an issue where incorrect links were generated to the configured ELK instance.

### Handling of call HTTP parameters with no name

Previously, HTTP query strings that specified a parameter with no (empty) name were incorrectly decoded by using the value as the name. For example, a call with the query string `=val1&key=val2` resulted in HTTP parameters `=val1` (incorrect) and `key` (correct). Parameters with no name are now ignored. So now this call has only a `key` parameter. The full query string can still be observed in the call details.

### Log Analytics filter suggestions

Fixed an issue where filter suggestions stopped working in **Analytics** > **Logs**.

### RBAC for Infrastructure

Fixed an issue where RBAC for Infrastructure required at least three characters in the Dynamic Focus Query (DFQ) for Custom Dashboards and Analyze Infrastructure. DFQ now supports queries with fewer than three characters.

### Synthetic monitoring

Resolved the security vulnerability `CVE-2025-27151`.

### Uninstalled agents that are shown as online

Fixed an issue in the Infrastructure area where uninstalled agents and their monitored entities continued to show as online.
