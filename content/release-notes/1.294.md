## Features

The following features are added in release 1.0.294:

### Synthetic monitoring

A new test type, DNS, is added to perform DNS query tests. For more information, see [Monitoring endpoints with Synthetic tests](https://www.ibm.com/docs/en/instana-observability/current?topic=monitoring-endpoints-synthetic-tests).


You need to upgrade the Synthetic PoP to 1.2.14 to obtain support for the new DNS capability.

### Weasel W3CHeader support

Weasel Agent version 1.7.5 now includes a new feature called W3C Header support. This update allows the agent to support W3C-compliant headers in requests to the backend. From Weasel Agent version 1.7.5, Instana can monitor websites with OpenTelemetry (OTEL) instrumented backends, even without the Instana agent on the backend. This enhancement broadens the range of applications that you can monitor to ensure complete system visibility regardless of the backend's instrumentation.

For more information, see [W3CHeader support](https://www.ibm.com/docs/en/instana-observability/current?topic=websites-javascript-agent-api#support-w3c-trace-headers-for-backend-correlation).

## Improvements

The following improvements are provided in release 1.0.294:

### Create automation action scripts from GitHub or Gitlab

You can create an automation action script from a GitHub repository or a GitLab project file. For more information, see [Intelligent Remediation: live action generation with watsonx (public preview)](https://www.ibm.com/docs/en/instana-observability/current?topic=ma-intelligent-remediation-live-action-generation-watsonx-public-preview).

### Export generated scripts to GitHub or GitLab

You can export the [scripts generated with watsonx](../../automation/intelligent-remediation/index.md#generating-script-actions-with-watsonx) to a GitHub repository or a GitLab project. For more information, see [Intelligent Remediation: live action generation with watsonx (public preview)](https://www.ibm.com/docs/en/instana-observability/current?topic=ma-intelligent-remediation-live-action-generation-watsonx-public-preview).

### Unified Identity Provider configuration

The Identity Providers are now displayed as a single tab. You can view the status of all authentication providers at once. For more information, see [Configuring authentication](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-configuring-authentication).

### Business monitoring is now Business processes

The name of the Business monitoring area has been changed to Business processes.
