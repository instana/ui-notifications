## Improvements

The following improvements are provided in release 1.0.312:

### Custom call metrics

The [custom call metrics](https://www.ibm.com/docs/en/instana-observability/saas?topic=applications-custom-call-metrics) are now displayed in the call details.

### MCP tool metrics

Now you can monitor Model Context Protocol (MCP) tool metrics on the Instana UI. For more information, see [Monitoring tool usage](https://www.ibm.com/docs/en/instana-observability/saas?topic=features-monitoring-tool-usage).

## Fixes

The following issues are fixed in release 1.0.312:

### Tag descriptions

This release adds and updates tag descriptions that were missing or incomplete.

### Synthetic monitoring

The following security vulnerabilities are fixed on Synthetic PoP:
- CVE-2025-15284
- CVE-2025-53066
- CVE-2025-64718
