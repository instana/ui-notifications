## Improvements

The following improvements are provided in release 1.0.319:

### Configure Kubernetes Smart Alerts on the cluster and namespace dashboards

You can now configure Kubernetes Smart Alerts from the cluster and namespace dashboards. This capability streamlines alert setup within the Kubernetes monitoring workflow. For more information, see [Smart Alerts for Kubernetes](https://www.ibm.com/docs/en/instana-observability?topic=kubernetes-smart-alerts).

### Filter calls from websites and mobile applications

You can now filter calls from a website or mobile application on the "Analytics" page by using the website or mobile application ID. Enable fast triage for this filter to work.

### Infrastructure correlation for MS SQL databases

Instana now supports infrastructure correlation for calls to remotely monitored Microsoft SQL Server databases. For successful correlation, the calls must use a host or cluster name that uniquely matches the name reported from the database infrastructure entity.

### OpenTelemetry traces

Improved the rendering of general span semantic attributes in call details.

## Fixes

The following issues are fixed in release 1.0.319:

### Infrastructure comparison table

Previously, when you changed the page size of the **Comparison table** on the **Infrastructure** dashboard, the update failed and the page size did not change. This issue is now resolved.

### Synthetic monitoring

The following security vulnerabilities are fixed on Synthetic PoP:

- CVE-2026-40895
- CVE-2026-42043
- CVE-2026-22741
