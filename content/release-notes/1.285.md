# Build 285

2024-10-28

## Features

### Download widgets as PDF in custom dashboards

Now you can download the tiles in a custom dashboard as PDF files. The **Download PDF** option is added in the **More** menu. In addition, you can select data in a graph and right-click, and then select **Download PDF**.


### Support for more than 3000 metrics per entity

Instana now supports ingestion of more than 3000 metrics per entity, with some restrictions. For more information, see [Monitoring infrastructure](https://www.ibm.com/docs/en/instana-observability/saas?topic=instana-monitoring-infrastructure).


### Trace errors and logs for probable root cause

For an Instana incident that has a probable root cause identified, now you can view its associated trace errors and logs. 


## Improvements
### Synthetic monitoring

The [synctl](https://github.com/instana/synthetic-synctl) tool now supports the following functions:

- Retrieve the list of Synthetic data centers
- Retrieve the details of a Synthetic data center with its ID 
- Update a Synthetic credential and associations


## Fixes
### Application perspectives

Previously, when the maximum line and the mean latency line were displayed at once, the maximum line hid the mean latency line, which caused difficulty in identifying the mean latency line. Now, the **Latency** chart on the Application, Service, or Endpoint dashboard is updated to view the mean latency line easily when it appears with other percentile and maximum series. The issue is now fixed.


### Synthetic monitoring

- The Synthetic PoP 1.2.6 images are now based on Red Hat UBI 9 images. 
- The security vulnerability `CVE-2024-4067` is fixed now.


### Trace details

Previously, when you sorted the **Service Endpoint List**, the list displayed inconsistent results. The issue is now fixed and displays consistent results in the **Service Endpoint List** across multiple pages.
