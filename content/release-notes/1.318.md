## Features

The following features are added:

### Incident prefix

When you create incidents, you can assign a unique serial ID for easier reference inside and outside the platform. The serial ID is alphanumeric text with a customized prefix that you set. The system automatically generates the number portion of the ID for each incident when you enable and configure the incident prefix.

The incident prefix appears on incidents in the following outbound integrations: bidirectional MS Teams, bidirectional Slack, generic webhook, email, and ServiceNow. For more information, see [Incident Prefix](https://www.ibm.com/docs/en/instana-observability/latest?topic=alerts-configuring-incident-prefix).

### Teams association

Team associations are now displayed on issue and incident detail pages when the entity that generates triggers is already assigned to a team. This enhancement helps teams quickly identify the ownership and engage the appropriate stakeholders during investigations.

Websites, mobile applications, synthetic tests, and SLOs currently trigger alerts that support this capability.

## Improvements

The following improvements are provided:

### UI changes in Smart alerts for synthetic

Synthetic smart alert creation dialogs are replaced with new Carbon tear sheets. Now you can configure synthetic Smart Alerts in a wider tear sheet view with a step-by-step workflow.

## Fixes

The following issues are fixed:

### Language support in Infrastructure widget

Previously, metrics were not displayed for some languages in the Infrastructure widget on the welcome page. This issue is now fixed.
