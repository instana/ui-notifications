Note:
For the latest agent, tracer, and sensor updates, see the following release notes:

- [Sensor releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-sensor)
- [Tracer releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-tracer)

## Features

The following features are added in release 1.0.296:

### Smart Alerts for mobile app

A new blueprint, **slowness**, with the metric `HTTP latency` is added in Smart Alerts for mobile apps. With this metric, you can create alerts based on the `beacon duration` of `HTTP requests`.

## Improvements

The following improvements are provided in release 1.0.296:

### Support for Windows Hyper-V monitoring (public preview)

You can now monitor Windows hypervisor hosts. For more information, see [Monitoring Windows Hyper-V (public preview)](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-windows-hyper-v-public-preview).

### Improved global dynamic custom payload support

Smart Alerts for logs and infrastructure now support global dynamic custom payloads.

## Fixes

The following issues are fixed in release 1.0.296:

### Synthetic monitoring

- The security vulnerability, which is CVE-2024-12798, is fixed in Synthetic PoP.

### Synthetic endpoint indicator

Previously, the synthetic endpoint indicator was missing from both the Endpoints list on the Service dashboard and the endpoint dashboard. This issue is fixed now.
