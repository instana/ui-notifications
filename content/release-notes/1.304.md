## Features

The following features are added in release 1.0.304:

### Reporting Status for hosts

The historical availability of a host is now displayed in the **Reporting Status** chart on the host dashboard. This chart provides details on when a host was or wasn't reporting to Instana.

### Synthetic monitoring

For each Synthetic test, a list of test results along with error messages is available on the **Synthetic tests** page.

## Improvements

The following improvements are provided in release 1.0.304:

### Populating empty objects in live tail of logs (public preview)

Many log messages in the log console contained empty objects. This issue is fixed. Now, those objects are populated with the correct data.

### PV and PVC monitoring in Kubernetes clusters

Persistent Volume (PV) and Persistent Volume Claim (PVC) resources are now displayed on the cluster page. The page view provides details such as utilization, pod association, and capacity.

### Scheduled policies

You can now schedule automation policies to run automatically, either once at a specific time or repeatedly based on a recurrent rule.

### Synthetic monitoring

- The Type, Location, and Association filter options now appear in a filter panel on the Synthetic tests page.
- The column selection on the Synthetic tests page now persists across user sessions.
- The [Synthetic PoP BrowserScript Playback Engine local runner](https://github.com/instana/synthetic-browser-script) now supports Node.js 22 and Chromium 139.

## Fixes

The following issues are fixed in release 1.0.304:

### Incorrect color mapping in graph legend

The **Warn** level in the graph legend was displayed in blue and the **Info** level in yellow, which was reversed. This issue is fixed. Now, the **Warn** level appears in yellow and the **Info** level in blue.

### Incorrect validation in delete logs v3

The system allowed log deletion without a valid date, which caused crashes if the date field was empty. This issue is now fixed. Now, you must select a valid date before you continue to delete logs.

### Synthetic monitoring

- The Synthetic PoP JavaScript Playback Engine displayed the "URL is not defined" error. This issue is now fixed. 
- The [synctl](https://github.com/instana/synthetic-synctl) tool could not support multiple custom payloads when a Synthetic Smart Alert was created or updated. This issue is now fixed.
- The following security vulnerabilities are fixed in Synthetic PoP: 

    - CVE-2025-48924
    - CVE-2025-41234
