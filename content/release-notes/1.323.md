## Features

The following features are added in release 1.0.323:

### LLM Trajectory view

Use the **Trajectory** view to inspect every step in an agent or LLM call. When you open a trace that contains agent or LLM calls, you can access the **Trajectory** view to examine the complete execution trace that includes every prompt, tool call, and model response.

The view presents each agent task as a numbered task entry. You can use the searchable list to navigate to any task, and the task detail panel to review the full context for that task. For more information, see [Monitoring LLMs](https://www.ibm.com/docs/en/instana-observability?topic=features-monitoring-llms#llm-task-view-in-trace-details__title__7).

### Maintenance window support for automation policies

You can now configure automation policies to support maintenance windows. When you create or edit a policy, you can choose to run the policy regardless of active maintenance windows or to suppress it during specific maintenance windows. This feature is available for both automatic and scheduled policies. For more information, see [Creating an automation policy](https://www.ibm.com/docs/en/instana-observability?topic=actions-automation-policies).

### Matched LDAP groups for role mapping

Instana supports role mappings based on the LDAP groups that the user belongs to, as determined by the LDAP group query. Instana adds the matched groups to the user's profile as a `groups` attribute.

### Status chart for SLO widgets

Custom dashboard SLO widgets now support the **Status chart** chart type. The **Status chart** displays SLO compliance as a percentage over time and includes a threshold line for the configured SLO target value.. For more information, see [Service level objectives widgets](https://www.ibm.com/docs/en/instana-observability?topic=objectives-service-level-widgets).

## Improvements

The following improvements are provided in release 1.0.323:

### Alerts lane improvements in SLO dashboard charts

The alerts lane in SLO dashboard charts now displays only the alert events for the SLO being monitored. Previously, the alerts lane showed all alert events regardless of the SLO. Also, the alerts lane is now available for all entity types, including Infrastructure, Mobile, and Synthetic SLOs.


### DBmarlin integration for more database access methods

DBmarlin database integration now supports additional database access methods, including the Python `SQLAlchemy` library. After you configure and enable a [DBmarlin database integration](https://www.ibm.com/docs/en/instana-observability?topic=integrations-dbmarlin), the trace detail view displays the **Find SQL in DBMARLIN** button for calls that target a database type that DBmarlin supports.

### Enhanced technology detection for C++ OpenTelemetry-instrumented services

Instana now correctly detects and displays the technologies associated with services instrumented with C++ OpenTelemetry SDKs, such as Envoy, NGINX, PHP, and HAProxy.

### Outside operator for adaptive infrastructure Smart Alert thresholds

Adaptive thresholds for infrastructure Smart Alerts now support the **Outside** operator, extending the range operators introduced for static thresholds in release 1.0.322. You can define upper and lower bounds around an adaptive baseline and trigger an alert when a metric value falls outside that range. For more information, see [Smart Alerts for infrastructure](https://www.ibm.com/docs/en/instana-observability?topic=infrastructure-smart-alerts).

### Redesigned Smart Alert configuration for websites and mobile apps

The Smart Alert create and edit workflows for websites and mobile apps now use a wider, step-by-step panel. You can select the alert blueprint and scope, configure thresholds and time-window conditions, and preview potential alerts in a single workflow. For more information, see [Smart Alerts for websites](https://www.ibm.com/docs/en/instana-observability?topic=websites-smart-alerts) and [Smart Alerts for mobile apps](https://www.ibm.com/docs/en/instana-observability?topic=applications-smart-alerts-mobile).
