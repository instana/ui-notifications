Note:

For the latest agent, tracer, and sensor updates, see the following release notes:

- [Agent releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-agent)
- [Sensor releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-sensor)
- [Tracer releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-tracer)


## Features

The following features are added in release 1.0.307:

### Websites business impact

The Business impact dashboard enables users to see how releases and alerts impact a website's business metrics like active sessions, users, and top pages. For more information, see [business impact for websites](../../website_monitoring/business_impact.md).

### Synthetic monitoring

- New Synthetic monitoring endpoint is available to support bulk delete Synthetic tests. For more information, see [OpenAPI](https://instana.github.io/openapi/#operation/bulkDeleteSyntheticTests).
- New Synthetic monitoring endpoint is available to support bulk update Synthetic tests. For more information, see [OpenAPI](https://instana.github.io/openapi/#operation/bulkUpdateSyntheticTests).
- Synthetic PoP JavaScript playback engine now supports `oracledb` Node.js module.

### OAuth support for webhook alert channel

Now you can integrate webhook alert channels with services that require OAuth 2.0 authorization. When OAuth is enabled for a webhook channel, Instana automatically manages the access token lifecycle—handling, token acquisition, refresh operations, and securely appending the token to outbound webhook requests as a Bearer token.

For more information, see [Webhook alert channel](https://www.ibm.com/docs/en/instana-observability/latest?topic=alerting-webhooks).

## Improvements

The following improvements are provided in release 1.0.307:

### Automation policies

Automation policies can now run automatically when an event is raised or closed. For more information, see [automation policies](https://www.ibm.com/docs/en/instana-observability/latest?topic=actions-automation-policies).

### OpenTelemetry calls

OpenTelemetry tags that are used for service and endpoint mapping (`otel_resource.service.name`, `otel.peer.service`, and `otel.operation`) are now always available as [dynamic tags](https://www.ibm.com/docs/en/instana-observability/latest?topic=os-traces#analyzing-opentelemetry-calls), even when the limit of 500 OpenTelemetry attributes is exceeded.

### Synthetic monitoring

The Synthetic PoP BrowserScript playback engine now uses Chromium 138.

### Tag descriptions

This release adds and updates tag descriptions that were missing or incomplete.

### Share feedback For Instana

Instana users can now share their feedback on Instana directly with the product team. You can access the feedback form by opening the AssistMe help panel and clicking **Give Feedback**. Provide your feedback by highlighting areas of success and opportunities for enhancement. Your insights are invaluable in the continuous effort to optimize Instana for your needs.

## Fixes

The following issues are fixed in release 1.0.307:

### Application Perspectives

Fixed an issue where messaging calls might sometimes be incorrectly omitted from the "Inbound" calls of an application perspective. The issue might occur when those calls were also included in another application perspective with the scope "Immediate downstream database and messaging services."

### Synthetic monitoring

- The following security vulnerabilities are fixed in Synthetic PoP:

    - CVE-2024-21145
    - CVE-2025-7783
    - CVE-2025-8916
    - CVE-2025-21502
    - CVE-2025-41242
    - CVE-2025-41249
- `serviceId` is deprecated in the Synthetic test result model. It is no longer available in the Synthetic tag catalog.
