# Release 1.0.299

Release 1.0.299 is released on 30 June 2025.

Note:
For the latest agent, tracer, and sensor updates, see the following release notes:

- [Agent releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-agent)
- [Sensor releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-sensor)
- [Tracer releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-tracer)

## Features

The following features are added in release 1.0.299:

### Cassandra

The Tombstone metrics (marker indicating a deletion) are now included in the dashboards. 

For more information, see [Monitoring Cassandra](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-cassandra).

### OpenTelemetry span events and span links (public preview)

You can now view OpenTelemetry span events and span links in the Instana UI if you set them in your OpenTelemetry trace.

For more information, see [OpenTelemetry span events and span links](https://www.ibm.com/docs/en/instana-observability/current?topic=os-traces#opentelemetry-span-events-and-span-links).

### Synthetic monitoring: Support for '@ibm-cloud/secrets-manager'

Synthetic PoP JavaScript playback engine now supports the integration of `@ibm-cloud/secrets-manager`. 

## Improvements

The following improvements are provided in release 1.0.299:

### Synthetic monitoring

- The Node.js version in Synthetic PoP JavaScript playback engine and BrowserScript playback engine is upgraded to v22. The Node.js version supports only the CommonJS module system.
- The [synctl](https://github.com/instana/synthetic-synctl) tool is enhanced to include the DNS test type in capacity planning.

### Windows Hyper-V 

The Windows Hyper-V dashboards are enhanced with new metrics for both host and virtual machine dashboards. 
For more information, see [Monitoring Windows Hyper-V (public preview)](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-windows-hyper-v-public-preview).

## Fixes

The following issues are fixed in release 1.0.299:

### Podman Image Name

Previously, the **Podman Image Name** call tag contained the image ID instead of the image name. This issue is now fixed.

### Synthetic monitoring

An error in the [synctl](https://github.com/instana/synthetic-synctl) tool prevented associating a test with applications whose IDs start with "-". This issue is now fixed.
