## Features

The following features are added in release 1.0.301:

### Synthetic monitoring

You can now use a new Synthetic monitoring endpoint to retrieve test result data based on a specified analytic function. For more information, see [OpenAPI](https://instana.github.io/openapi/#operation/getSyntheticResultAnalytic).

## Improvements

The following improvements are provided in release 1.0.301:

### Log Smart Alerts now support regex-based filtering

Log Smart Alerts now support the **RegEx** operator matching in filters, enabling you to define more expressive pattern-based conditions. For more information, see [Smart Alerts for log](../../logging/smart_alerts.md#defining-the-scope).

### Log Collector for .NET Applications

You can collect and download .NET logs for different components from the Instana UI. For more information, see [Collecting logs](../../ecosystem/dot-net-core/index.md#collecting-logs).

### New Role-based access control and Teams (public preview)

User management is enhanced. Instead of groups, roles and teams are used. You can assign roles to users directly or have different roles apply to them when part of a team. Limited access scopes are now part of the team configuration. For more information, see [Managing user access](../../admin/manage-users.md).

The existing groups are preserved as “roles” and the users in those groups are not affected by the change. The admins can [create a new team](#create-a-new-team) and add users. Groups with a limited scope are preserved as roles with a “limited scope” tag on them, and you can edit them.

### Oracle RAC built-in events for inactive instances

The built-in event for the Oracle RAC is generated when the active instances count decreases.

### Synthetic monitoring

The `redis-tls-not-enabled` monitoring issue is now removed from the Synthetic PoP sensor.

## Fixes

The following issues are fixed in release 1.0.301:

### Infra linking

Previously, ACE Services created from OpenTelemetry calls did not have Technology associated with them. This issue is now fixed.

### Markdown rendering

The custom dashboards now render markdown correctly. Previously, the markdown rendering on custom dashboards were not working correctly for headings or lists. This issue is now fixed.

**Supported:** Lists (both ordered and unordered), headings, bold, italics, strikethrough, code, and blockquotes.

**Not supported:** HTML tags and task list, for example "- [x] item". 

### Nutanix missing icons and incorrect datacenter name

The incorrect datacenter name and the missing icon for the Nutanix VMs are now fixed.

### Windows Hypervisor host and VM metric units

The incorrect metric units for the Windows Hypervisor sensor that are displayed on the "Analyze infrastructure" page are now fixed.
