# Release 1.0.298

Release 1.0.298 is released on 16 June 2025.

Note:
For the latest agent, tracer, and sensor updates, see the following release notes:

- [Agent releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-agent)
- [Sensor releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-sensor)
- [Tracer releases](https://www.ibm.com/docs/en/instana-observability/current?topic=notes-tracer)

## Features

The following features are added in release 1.0.298:

### Custom dashboards for business metrics

You can now create custom dashboard widgets for user-defined business metrics. The following chart types are supported:

* Big number
* Pie chart
* Time series chart
* Top list

For more information, see [Business metrics (public preview)](https://www.ibm.com/docs/en/instana-observability/current?topic=business-metrics).

### App state identification for iOS and Android applications

You can now view the state of the application for each beacon, whether it is running in the foreground, background, or if the state is undetermined. This enhancement provides deeper insights into application behavior across different contexts.

For more information, see [Analyze application state for debugging and analytics](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-monitoring-mobile-applications#analyze-application-state-for-debugging-and-analytics)..

### Per entity alerting in Smart Alerts for infrastructure

You can now configure per entity alerting in infrastructure smart alerts. With this alerting method, you can monitor each metric individually and trigger an alert against each individual entity.

For more information, see [Smart Alerts for infrastructure](https://www.ibm.com/docs/en/instana-observability/current?topic=infrastructure-smart-alerts#defining-the-scope).


### Single entity LLM-based investigation (public preview)

You can now investigate Instana incidents with probable root cause by clicking **Investigate for Me** on the **Incidents** dashboard. Access to this feature is currently limited to select customers in certain SaaS regions. For more information, see [Single entity LLM-based investigation](https://www.ibm.com/docs/en/instana-observability/current?topic=capabilities-root-cause-analysis#single-entity-llm-based-investigation) and contact Instana support if needed.

## Improvements

The following improvements are provided in release 1.0.298:

### Automation policy dashboard

A new dashboard is added for Automation policy. For more information, see [Policy dashboard](https://www.ibm.com/docs/en/instana-observability/current?topic=actions-automation-policies).

### Combined UI for Recommended Actions and Policies in an Event

Previously, the event, issue, or incident page had two separate tabs for Policies and Recommended Actions. This release combines both into a single table. Now, the Policies appear at the beginning of the table, followed by the Recommended Actions.

### Synthetic monitoring

- You can now customize the **Tests** table view by selecting the **Settings** icon to show or hide the specific table columns based on your preferences.
- For SSL certificate tests, you can now see the number of remaining days until expiration in the **Type** column of the **Tests** table.
- In the **Create Synthetic test** form in advanced mode, added "(optional)" indicators next to non-required fields to improve the form clarity and the user experience.

## Fixes

The following issues are fixed in release 1.0.298:

### Dynamic tag visibility

Previously, newly received OpenTelemetry tags did not appear immediately in the filter and grouping selection within Application Analytics. This issue is now fixed.

### EUM Mobile app performance dashboard

Previously, when viewing both iOS and Android cold start times together, the application **Cold start time** chart displayed an integral graph instead of a continuous line graph. This issue is now fixed.

### Synthetic monitoring

- An execution error in the Synthetic PoP JavaScript playback engine that occurred when using `$network` to configure a proxy connection is now fixed.
- An error in the [synctl](https://github.com/instana/synthetic-synctl) tool that prevented associating a test with applications is now fixed.
