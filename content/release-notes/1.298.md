## Features

The following features are added in release 1.0.298:

### Per entity alerting in Smart Alerts for Infrastructure

You can now configure per entity alerting in infrastructure smart alerts. With this alerting method, you can monitor each metric individually and trigger alert against each individual entity.

For more information, see [Smart Alerts for Infrastructure](https://github.ibm.com/instana/docs/blob/main/src/pages/infrastructure_monitoring/smart_alerts.md#defining-the-scope).
