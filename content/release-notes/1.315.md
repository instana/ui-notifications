## Features

The following features are added:

### Run Instana agent as a non-root user on Linux (public preview)

You can now run the Instana agent as a non-root user on Linux platform and maintain full monitoring capabilities. This feature is available as a public preview. For more information about installation and configuration details, see the [agent non-root installation instructions](https://www.ibm.com/docs/en/instana-observability/saas?topic=il-running-agent-as-non-root-user-linux-public-preview).

### Calendar month support for service level objectives

Service level objectives (SLOs) now support calendar month time windows for fixed time window configurations. For more information, see [Service level objectives](https://www.ibm.com/docs/en/instana-observability/saas?topic=slos-service-level-objectives).

### Windows support for OTEL Collector installation

You can now install the OpenTelemetry Collector by using windows platform directly from the Instana UI. Previously, these installations required following external documentation. Now, the Instana UI automatically displays the appropriate installation commands.

### Graph explorer for infrastructure

A new [graph explorer](https://www.ibm.com/docs/en/instana-observability/saas?topic=infrastructure-graph-explorer) view is available on the **Infrastructure** dashboard that provides a visual representation of infrastructure entities and their relationships using a node‑and‑edge graph layout.

### Monitoring Microsoft SQL Server Always On Availability Groups (AG)

The Microsoft SQL Server sensor now supports monitoring Always On Availability Groups (AG), collecting metrics at both the instance level and the Availability Group entity level. For more information, see [Monitoring Microsoft SQL Server](https://www.ibm.com/docs/en/instana-observability/saas?topic=technologies-monitoring-microsoft-sql-server).

### AI Evaluation within GenAI observability

Instana now supports AI evaluation within the GenAI Observability tab. You can evaluate traces by using predefined evaluators or create custom evaluators to define your own evaluation criteria and assess LLM outputs accordingly. For more information, see [AI evaluation in Instana](https://www.ibm.com/docs/en/instana-observability/saas?topic=features-ai-evaluation-in-instana)

## Improvements

The following improvements are provided:

### Approximate ingestion values in data granularity table

The data granularity table is extended to provide approximate ingestion volumes for all data types that include services and endpoints, EUM websites and applications, and synthetic tests.

### Hot storage expansion for logs

Instana now stores logs in hot storage for 7 days instead of 1 day. This improvement provides frequent, low-latency access, and supports real-time queries for the full 7-day period. This change does not affect log retention periods.

## Fixes

The following issues are fixed:

### Filtering and grouping on HTTP headers with periods in the name

Backend trace processing did not correctly handle HTTP headers that contain periods (`.`) in the header name. Therefore, filtering and grouping on such headers returned incorrect results. This issue is now fixed.

### Synthetic monitoring

The following security vulnerabilities are fixed on Synthetic PoP:

- CVE-2025-5115
- CVE-2026-1225
- CVE-2026-27699
