# Build 315

2026-03-09

## Features

The following features are added in release 1.0.315:

### Calendar month support for service level objectives

Service level objectives (SLOs) now support calendar month time windows for fixed time window configurations. For more information, see [Service level objectives](../../service_level_objectives/slo_capabilities.md).

### Windows support for OTEL Collector installation

You can now install the OpenTelemetry Collector by using windows platform directly from the Instana UI. Previously, these installations required following external documentation. Now, the Instana UI automatically displays the appropriate installation commands.

### Graph explorer for infrastructure

A new [graph explorer](../../infrastructure_monitoring/graph-explorer.md) view is available on the **Infrastructure** dashboard that provides a visual representation of infrastructure entities and their relationships using a node‑and‑edge graph layout.

### Monitoring Microsoft SQL Server Always On Availability Groups (AG)

The Microsoft SQL Server sensor now supports monitoring Always On Availability Groups (AG), collecting metrics at both the instance level and the Availability Group entity level. For more information, see [Monitoring Microsoft SQL Server](../../ecosystem/microsoft-sql-server/index.md).

## Improvements

The following improvements are provided in release 1.0.315:

### Approximate ingestion values in data granularity table

Extended the data granularity table to provide approximate ingestion volumes for all data types that include services and endpoints, EUM websites and applications, and synthetic tests.

## Fixes

The following issues are fixed in release 1.0.315:

### Filtering and grouping on HTTP headers with periods in the name

Previously, backend trace processing did not correctly handle HTTP headers that contain periods (`.`) in the header name. Therefore, filtering and grouping on such headers returned incorrect results. This issue is now fixed.
