# Build 289

Build 289 is released on 27 January 2025.

## Features

The following features are added.

### Business monitoring custom dashboard support

You can now use business monitoring data to create widgets of the following types within your custom dashboard:

* Big Number
* Pie Chart
* Time Series Chart
* Top List

### Cost observability and allocation with IBM Kubecost (public preview)

Instana now supports IBM Kubecost. For more information, see [Integrating with IBM Kubecost](https://www.ibm.com/docs/en/instana-observability/current?topic=apis-integrating-kubecost-public-preview).

### Kubernetes Horizontal Pod Autoscaler monitoring

Instana now enables the monitoring of Kubernetes Horizontal Pod Autoscaler by default. However, you can opt out of this feature if it is not required. For more information about enabling and disabling optional features, see the [Enabling optional features(Docker)](https://www.ibm.com/docs/en/instana-observability/current?topic=ice-enabling-optional-features) or [Enabling optional features (Kubernetes or OpenShift Container Platform)](https://www.ibm.com/docs/en/instana-observability/current?topic=configuring-enabling-optional-features) documentation.


## Improvements

The following improvements are provided.

### New metrics for LLM monitoring

Instana LLM monitoring now supports the following metrics, which are aggregated by the LLM model and applications:
* Total Input Tokens
* Total Output Tokens
* Total Input Cost
* Total Output Cost

### Service level objectives (SLO)

The **Create Service Level Objective (SLO)** dialog box now displays the correct units for websites and synthetic tests.

### Synthetic monitoring

By default, the **Results** page is sorted in descending order based on the **Started** column. 

## Fixes

The following fix is provided.

### Charting of custom call metrics with negative values

Previously, the *mean* aggregation chart for custom call metrics with negative values displayed invalid data. This issue is now fixed.
