# Build 286

2024-11-18

## Features
### Limited access RBAC for Business Monitoring
You can now select the **Limited access** permission scope for **Business Monitoring** while managing user groups.
Users in a group with limited access can view only the business perspectives and processes to which they are explicitly granted access to.
For more information, see [Manage user access](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-managing-user-access#business-monitoring).

### Synthetic monitoring new metrics API
A new Synthetic monitoring endpoint is available to retrieve metrics of Synthetic test results.
With this API, you can group the results by tags other than the Synthetic test ID.
By default, the test results are grouped by test ID.
For more information, see [OpenAPI](https://instana.github.io/openapi/#operation/getMetricsResult).

## Improvements
### Monitoring large language models
The large language model (LLM) monitoring now supports the following features:
  * Monitoring of AWS Bedrock applications
  * Log monitoring for LLM applications
  * Agentless ingestion for OpenTelemetry (OTel) Data Collector to send data directly to the Instana backend

For more information, see [Monitoring LLMs](https://www.ibm.com/docs/en/instana-observability/current?topic=technologies-monitoring-llms).

### The *Access Control* and *Audit* options are moved
The **Team Settings** tab in the **Settings** menu is renamed as **Global Settings**.
The following options are moved from the **Team Settings** tab to the **Security & Access** tab:
* **Access Control**
* **Audit**
* **Identity Providers**
* **Session**

For more information on the **Access Control** and **Audit** options, see [Manage Users]([../../admin/manage-users.md](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-managing-user-access)). 
For more information on the **Identity Providers** and **Session** options, see [Authentication]([../../admin/authentication.md](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-configuring-authentication)).

## Fixes
### OpenTelemetry endpoint mapping
Previously, some calls created from OpenTelemetry spans were mapped to a fallback endpoint **Unspecified**. This issue is now fixed.
