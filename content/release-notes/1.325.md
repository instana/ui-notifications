## Features

The following features are added in release 1.0.325:

### Burn rate chart for service level objectives (SLO) widgets
SLO widgets on custom dashboards now support **Burn rate chart**. When you select this chart type, you can select the default burn rate windows the chart displays. To hide the chart summary on any SLO widget, disable **Show chart summary** on the widget settings. For more information, see [SLO widgets](https://www.ibm.com/docs/en/instana-observability/saas?topic=objectives-service-level-widgets).

### Notifications for policies
You can now configure policies to send notifications to alert channels when an action lifecycle event occurs, such as when an action starts, completes successfully, fails, or times out. Notification configuration is optional and is set per policy. For more information, see [Creating an automation policy](https://www.ibm.com/docs/en/instana-observability/saas?topic=actions-automation-policies).

### SLO event details: Alert-aware charts
When you open an SLO alert event in the **Events** view, the **Event Details** panel displays a chart that matches the alert type that triggered the event. Status, error budget consumed, and burn rate alerts each show their respective chart. Each chart overlays the configured alert threshold, styled in warning or critical colors.  For more information, see [Alert-aware charts in event details](https://www.ibm.com/docs/en/instana-observability/saas?topic=slos-service-level-objectives)
