## Improvements

The following improvements are provided in release 1.0.303:

### Synthetic monitoring

The [synctl](https://github.com/instana/synthetic-synctl) tool is enhanced to support the new endpoint that retrieves test result data based on a specified analytic function.

## Fixes

The following issues are fixed in release 1.0.303:

### Incorrect root span creation in OpenTelemetry traces

Previously, when OpenTelemetry traces began with an exit span, Instana incorrectly generated a synthetic root span. The issue is now resolved, and Instana correctly handles traces that start with exit spans without creating a fake root span.

### Synthetic monitoring

Previously, the Synthetic PoP BrowserScript playback engine could not connect to Redis if certificate chains are used. The issue is now fixed.
