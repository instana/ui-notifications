## Features

The following features are added in release 1.0.302:

### Grouping by tag in unbounded trace analytics

You can now group trace data by the `http.url` tag in unbounded analytics for traces. This feature was previously available only in unbounded analytics for calls. For more information, see [Unbounded analytics](https://www.ibm.com/docs/en/instana-observability/latest?topic=capabilities-unbounded-analytics).

### Synthetic monitoring

Assertions are supported in the **SSL certificate** test creation flow for validating conditions at run time.

## Improvements

### Synthetic monitoring

- The **Wizard Mode** is removed. The Synthetic test creation now uses a single, streamlined **Advanced Mode**.
- The uploaded script name is now displayed in both **API Script** test and **Browser Script** test configurations.
- The **popctl** tool now supports **pdcollect**. The **pdcollect** tool is available automatically after the Synthetic PoP installation.

## Fixes

### Synthetic monitoring

Security vulnerability CVE-2025-7783 is fixed in Synthetic PoP.
