## Features

The following features are added in release 1.0.302:

### Grouping by tag in unbounded trace analytics

You can now group trace data by the `http.url` tag in unbounded analytics for traces. This feature was previously available only in unbounded analytics for calls. For more information, see [Unbounded analytics](https://www.ibm.com/docs/en/instana-observability/saas?topic=capabilities-unbounded-analytics).

### Save and reuse log filters as named queries

You can now save filters that are applied in Analytics > Logs as a named query. This allows you to reuse the same filter configuration later or share the query with other users in your tenant. In addition, you can include grouping settings (for example, grouping by specific fields).

This feature was previously available only in Analytics > Calls.

For more information, see [Unbounded analytics](https://www.ibm.com/docs/en/instana-observability/saas?topic=capabilities-unbounded-analytics).

### Monitor live logs in real time (public preview)

You can now monitor live logs in Analytics > Logs to help quickly identify and resolve exceptions as the logs come into instana. This feature allows you to stream real-time log data and is particularly useful for Site Reliability Engineers (SREs) during active monitoring.

The Live Tail feature supports the following actions:

- Filter the incoming live log stream by using the standard log filters

- Search for specific error messages or keywords within the live view

- Click the specific log entry to navigate to [Unbounded analytics](https://www.ibm.com/docs/en/instana-observability/saas?topic=capabilities-unbounded-analytics) with the log reference preloaded

### Selectively delete logs using filtered criteria

You can now select logs and delete them from the database based on a filtered set of criteria. This capability is useful for self-service recovery, such as removing logs that contain accidentally ingested personally identifiable information (PII) or secrets.

The selective log deletion feature allows you to do the following actions:

- Specify a start and end time for log deletion.

- Apply up to five filters to target the specific logs that you want to delete.

- Maintain system stability by allowing only one active deletion request per tenant at a time.

New deletion requests are blocked while another is in progress.

### Synthetic monitoring

Assertions are supported in the **SSL certificate** test creation flow for validating conditions at run time.

## Improvements

### Smart Alerts: Removed the floating action button
The floating button for creating Smart Alerts is removed. This functionality is now available directly within the Smart Alerts table.

The table displays an empty state with a clear call to action when no Smart Alerts are created.

### Account and billing

The **Account and billing** section is moved out of **Settings** and is now available directly in the Instana navigation menu.
This update provides quicker access and better visibility, helping you manage your account with greater ease.

### Synthetic monitoring

- The **Wizard Mode** is removed. The Synthetic test creation now uses a single, streamlined **Advanced Mode**.
- The uploaded script name is now displayed in both **API Script** test and **Browser Script** test configurations.
- The **popctl** tool now supports **pdcollect**. The **pdcollect** tool is available automatically after the Synthetic PoP installation.

## Fixes

### Contextual tag suggestions in Unbounded analytics

Tag suggestions in Unbounded analytics now take faceted filters into account. Previously, tag suggestions were shown based on the full dataset, ignoring any active faceted filters. Now, suggestions are scoped to the filtered dataset, which provides more relevant and contextual tag recommendations.

### Synthetic monitoring

Security vulnerability CVE-2025-7783 is fixed in Synthetic PoP.
