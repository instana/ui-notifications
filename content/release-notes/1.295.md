## Features

The following features are added in release 1.0.295:

### Cost observability and allocation with IBM Kubecost

Instana integration with IBM Kubecost for cost analytics is now generally available. You can configure and use this feature to make cost-informed decisions to manage the performance of your Kubernetes environment. You can see the cost allocation details by namespace, deployment, infrastructure usage, and so on.
For more information on the license conditions and to learn how to configure this integration, see [Integrating with IBM Kubecost](https://www.ibm.com/docs/en/instana-observability/current?topic=apis-integrating-kubecost).

### Support for W3C headers in mobile agents

Mobile agents, such as [android-agent (6.2.1 and later)](https://www.ibm.com/docs/en/instana-observability/current?topic=applications-android-api#setting-up-instana-monitoring), [iOS-agent (1.9.1 and later)](https://www.ibm.com/docs/en/instana-observability/current?topic=applications-ios-api#setting-up-the-instana-ios-agent), [react-native-agent(2.0.8 and later)](https://www.ibm.com/docs/en/instana-observability/current?topic=applications-react-native-api#backend-correlation-with-w3cheaders), and [flutter-agent (3.1.1 and later)](https://www.ibm.com/docs/en/instana-observability/current?topic=applications-flutter-monitoring-api#backend-correlation-with-w3cheaders), now support W3C-compliant headers in requests to the backend. Instana can now monitor mobile apps with OpenTelemetry-instrumented backends, even without the Instana agent on the backend. This enhancement broadens the range of applications that you can monitor, ensuring complete system visibility regardless of the backend's instrumentation.

## Improvements

The following improvements are provided in release 1.0.295:

### Cookie consent management

The cookie consent management feature in Instana is now moved from the **Settings** menu to the **Profile** menu. To view and update your cookie preferences, go to the **Profile** menu and click **Privacy**. TrustArc is used for cookie consent management and it helps to ensure compliance with global data privacy regulations by enabling users to make informed choices about their data. For more information, see [Privacy and compliance](https://w3.ibm.com/w3publisher/digital-behavior-data-management/privacy-and-compliance) and [Overview on Tealium and TrustArc](https://w3.ibm.com/w3publisher/digital-behavior-data-management/tag-management/tealium-overview).

### Synthetic monitoring

The Execution type column is now added to the **Results** tab. The value of the Execution type column is **Scheduled**.

To view the Execution type column, complete the following steps:

1. From the navigation menu in the Instana UI, select **Synthetic monitoring**.
2. On the Tests page, click a test item from the list.
3. Click the **Results** tab.

## Fixes

The following issues are fixed in release 1.0.295:
