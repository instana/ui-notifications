## Features

The following features are added in build 293:

### Business process flow map

The business process flow map now visually includes activity health details through color-coding. For more information, see [Viewing details for a business process](https://www.ibm.com/docs/en/instana-observability/current?topic=instana-business-monitoring).

### New layout for Kubernetes clusters and namespaces tabs

A new layout is available for Kubernetes clusters and namespaces tabs. The updated layout enhances the usability and navigation, providing a clearer and more structured view of clusters and namespaces information.

## Improvements

The following improvements are provided in build 293:

### Context selection for recommended actions for incident with Probable Root Cause

When an incident includes a **Probable root cause** section with supporting evidence, the **Recommended actions** section now has a **Context for** drop-down menu. You can select the context for the recommended actions from this menu. For more information, see the [Action recommendations](https://www.ibm.com/docs/en/instana-observability/current?topic=actions-action-recommendation#using-recommended-actions).

### Adaptive threshold Smart Alerts

Smart Alerts with adaptive thresholds now refresh the auto-detected seasonality in their model's daily.

### Synthetic monitoring

The **Results** tile in the **Summary** tab now shows the **Failed** tab by default.
